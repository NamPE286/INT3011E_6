# Shared AI engineering rules

These rules apply to all Tavyno repositories. Each repository's `AGENTS.md` links to the relevant files here and adds repository-specific rules nearby.

Read the shared files that apply to the task before editing code:

- [principles.md](principles.md) — priorities, simplicity, boundaries, and architecture
- [code-style.md](code-style.md) — TypeScript, naming, formatting, structure, and file size
- [testing.md](testing.md) — TDD, test scope, fixtures, and mocking
- [safety.md](safety.md) — validation, security, errors, secrets, and external systems
- [workflow.md](workflow.md) — change process, review, and definition of done
